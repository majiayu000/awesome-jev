# 网站资料来源

Awesome Jev 是社区维护的资源清单，与 TypeSafe 无隶属关系。

网站内容由 [完整目录](https://github.com/majiayu000/awesome-jev/blob/main/catalog/FULL.md) 生成，项目名称、描述与链接保持一致。来源归属与整理方法见 [SOURCE.md](https://github.com/majiayu000/awesome-jev/blob/main/SOURCE.md) 和 [目录来源说明](https://github.com/majiayu000/awesome-jev/blob/main/catalog/SOURCE.md)。

`data/entries.json` 是此前收集的历史记录，保留供查阅；其中的旧分类字段不用于当前页面。收录不代表已独立运行或验证项目。
