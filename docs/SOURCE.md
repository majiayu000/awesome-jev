# 网站资料来源

Awesome Jev 是社区维护的资源清单，与 TypeSafe 无隶属关系。

网站内容由 [完整目录](https://github.com/majiayu000/awesome-jev/blob/main/catalog/FULL.md) 生成，项目名称、描述与链接保持一致。来源归属与整理方法见 [SOURCE.md](https://github.com/majiayu000/awesome-jev/blob/main/SOURCE.md) 和 [目录来源说明](https://github.com/majiayu000/awesome-jev/blob/main/catalog/SOURCE.md)。

`data/entries.json` 是此前收集的历史记录，保留供查阅；其中的旧分类字段不用于当前页面。收录不代表已独立运行或验证项目。

## 视觉与插画

本页使用维护者 Spellbook 的 Illustrated Gallery 设计指导，按 Jev 的用途重新设计整页。未复用旧模板的花卉、锦鲤、白鹭、月夜或人物素材。

`assets/decision-paths.webp` 与 `assets/evaluation-study.webp` 使用内置 imagegen 为本项目生成，分别是路径选择与判断校准的概念插画，不是产品截图或真实测试装置。精选卡片的符号由 CSS 绘制，仅表示接入、浏览器和路由主题。

### 插画提示词

**Decision paths**

Wide 16:9 editorial artwork for the Awesome Jev open-source AI decision-model resource website. A physical decision-routing laboratory: precise ivory ceramic branching tracks crossing a circular graphite platform, one burnt-orange route choosing between paths, translucent amber prisms and brushed aluminum gates. Tactile architectural scale-model photography, slight analog grain, charcoal shadows, parchment ivory and rust accents. Elevated three-quarter view, subject slightly right, quiet dark space left, soft side lighting. No text, logos, screens, robots, botanical motifs, neon or generic AI brains.

**Evaluation study**

Wide 16:9 editorial illustration for Awesome Jev's evaluation and learning section. A physical precision-testing bench with ascending ivory ceramic platforms, a sculptural brushed-aluminum balance beam, amber calibration blocks, and an orange sphere on an unnumbered measurement track. A visual metaphor for comparing judgments against evidence. Warm paper backdrop, airy architectural studio, rich cast shadows, slight analog grain, elevated three-quarter view. Palette: parchment, graphite, ivory, rust-orange. No text, numerals, logos, screens, robots or plants. Conceptual still life, not a technical diagram.
