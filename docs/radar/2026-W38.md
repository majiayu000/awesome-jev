# Jev 社区动态 · 2026-09-15 至 2026-09-18

本期整理发布初期的公开资料。下列性能描述来自原作者，本仓库未独立复现；接入状态以服务商当前文档为准。

## 产品发布

TypeSafe 发布 Jev，通过 Choice、Score 和 Noul 返回选项、分数或条件判断，供软件继续处理。关于价格、速度和输出格式的承诺，需结合官方测试条件阅读。

来源：[发布文章](https://typesafe.ai/blog/introducing-system-one-models-and-jev) · [模型能力局限](https://docs.typesafe.ai/model-jaggedness/jev-1.13.md)。

## 浏览器自动化

[Browser Use Ultrafast](https://github.com/browser-use/jev-ultrafast) 使用 Jev 选择操作与 DOM 元素，输入文字时调用语言模型。作者展示了约 7 秒、0.0039 美元的航班搜索演示。这是一次演示的数据，不能据此推断所有网站上的成功率或成本。

来源：[作者演示](https://x.com/gregpr07/status/2100411066966749359)。

来源：[Vercel](https://vercel.com/ai-gateway/models/jev) · [Cloudflare](https://developers.cloudflare.com/ai/models/typesafe/jev/) · [OpenRouter 公告](https://x.com/OpenRouter/status/2100744709589316009)。
