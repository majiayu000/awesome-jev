## 评测 / 负结果 / 综述（增量）

1. **[arXiv:2609.39496 · When the Right Answer Is Missing…](https://arxiv.org/abs/2609.39496)**（USC / UF / Emory，提交约 **2026-09-30**）  
   配对「答案在菜单里 / 不在菜单里」：裸算术 Menu Choice 有答案时准确率约 **99%**，显式 `None` 时正确拒答仅约 **7%**；原生 Boolean 在同批无答案案上精确匹配约 **99%**——能核验却在类别拒答上塌方。两步运算已使拒答崩溃；采购合计、库存、时间换算等算术依赖场景同向；lookup / 政策类对照则间隙小。作者用开发集选出的阈值（如算术 `p(None)≥0.03`）把拒答抬到约 **79%**、有答案侧约 **97%**，无需重训或二次推理。相对官方 jaggedness「算术留给代码」与 09-30 Decision Hijacking：本项是 **不完全候选集上的拒答瓶颈**，不是注入。

2. **[arXiv:2609.36399 · Calibrated to Whom?…](https://arxiv.org/abs/2609.36399)**（Alfaisal / Proxa；数据采集约 **2026-09-28–29**，`jev-1.13.0`）  
   用 VSM 2013 + 匹配的沙特/美国人格，在英/阿与八种请求写法下共约 **28.8 万**次回答：无人格时默认贴近其美国人格；换沙特人格后英侧复现约 **87%** 的人类国家差方向与尺度、阿侧约 **62%**（差距主要来自**题干语言**而非人格描述语言）；年龄位移可与国籍同量级，性别刻板在沙特人格上更强；阿语与沙特人格下置信更低。长期取向维度方向与霍夫斯泰德参照相反。相对 09-28/29 的 judge / AITA：本项是 **决策模型当「受访者」时的文化默认与语言效应**，不是路由准确率。

3. **[arXiv:2609.32160 · Typed Decision Models: An Early Evidence Audit…](https://arxiv.org/abs/2609.32160)**（东北大学；投稿约 2026-09-26，此前 dig 未收录）  
   审读发布后约九日内 **28** 篇 TDM/Jev 相关稿：typed readout 尚未显示相对同骨干 label-probability 的独立准确率优势；清晰收益在延迟/成本；parity 常落在近天花板题；校准因工作负载而异；置信 cascade 常见但与廉价生成 cascade 的对照稀少。据此给出 **14 项**评测清单（B1 label-logprob 基线、T3 选项名不变性、C1 校准、C3 阈值 hold-out 等）并附语料合规计数。相对已合入 catalog 的 [2609.30216 生态 survey](https://arxiv.org/abs/2609.30216)：本项是 **方法学审计 + checklist**，不是 GitHub 生态盘点。

4. **[arXiv:2609.40241 · Decision-Oriented Recommendation Reranking…](https://arxiv.org/abs/2609.40241)**（SMU / Meta AI；提交约 **2026-09-30**；API 用 `jev-latest`）  
   Amazon Reviews 三域、硬候选 \(K\in\{20,50,100,200\}\)：Jev Choice 概率作重排分，对照 SASRec / DCNv2 与 Qwen2.5-7B 逐点/列表式。作者报告 Jev 在 NDCG@10 上相对上述基线保持强有效性，观测延迟随 \(K\) 增长显著缓于逐点 Qwen（托管 API vs 单卡本地，不可硬件归一）；常落在实验内非支配质量–延迟边界上。局限：单一决策模型、单一 7B LLM 对照、Jev 延迟含网络。相对既有 judge/agent 文：本项是 **推荐二阶段重排**应用对照。
