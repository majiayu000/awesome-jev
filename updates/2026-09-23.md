## 值得一看的工具（优先）

1. **[malevrigns/agent-jev](https://github.com/malevrigns/agent-jev)**（约 215★） + 权重 [aimeigaoshou/agent-jev](https://huggingface.co/aimeigaoshou/agent-jev)  
   开源 **AgentJev-0.6B**：Qwen3-0.6B 去掉生成头，一次前向给出 Boolean / Choice / Score 全分布，**解码 token = 0**。作者自报 Typed Decisions 上 top-1 约 79.25%（n=2000）；共享前缀缓存后示例负载中位约 299 ms。相对 09-22 的 [`rizzo-flow`](https://github.com/Rizzo-AI-Academy/rizzo-flow)（本机 logits 对齐 TypeSafe 形状）：本项是**专用小权重 + 置换等变头**，自称非 TypeSafe 附属。上下文硬顶 2048，超长直接拒。

2. **[miuuyy/Astra-Ares](https://github.com/miuuyy/Astra-Ares)**（约 159★）  
   给 Codex 任务里的 GPT-6 Astra / Sol / Luna **中途改 reasoning effort**：Jev 读有界任务上下文，选下一档思考深度与持续代数；依赖「改 effort 不使前缀缓存失效」。需单独打补丁的 Codex CLI 构建（约 10 GB 起），实验参考实现；默认经 OpenRouter 调 Jev。用途清楚：把决策模型嵌进**生成模型的思考档位**，而非又一个 classify MCP。

3. **[nokia-applied-research/AnyJev](https://github.com/nokia-applied-research/AnyJev)**（约 68★，PyPI `anyjev`）  
   把**任意已有 LLM** 读成 Jev 风格决策（无生成、无微调）：L0 零标注纠「选项顺序翻转」、L1 少量标注校准。作者自报 Qwen3-8B × BANKING77：翻转率 0.230→0.073，ECE 0.240→0.095，≤5% 风险可自动决策份额 7.7%→52.0%（n=300，区间宽）。明确 **非 TypeSafe 附属**；与 rizzo-flow / AgentJev 同属「本地/自有模型复刻决策形状」赛道，方法与可复现 bench 更完整。

4. **[andududu/jeview](https://github.com/andududu/jeview)**（约 38★）  
   非官方本地可视化网关：`代码 → Jeview(:4777) → TypeSafe`，SQLite 存每次调用并画实时图。无依赖（Node 24+）、仅监听 127.0.0.1；密钥明文落库、本机进程可读——作者写进安全段。直播里提到的「调试时必须能审计每次 TypeSafe 调用」的可跑实例。

5. **[ipenywis/laya-ultrafast](https://github.com/ipenywis/laya-ultrafast)**（约 116★）  
   [`browser-use/jev-ultrafast`](https://github.com/browser-use/jev-ultrafast) 的 **Laya 本地移植**（Apple Silicon / MLX）。窄问题 + 规则策略替代「下一步做什么」开放题；可切回 `DECISION_MODEL=typesafe`。与 09-21 Chrome 移植、09-22 `rizzo-flow` 互补：浏览器环 + 开源决策权重。旁注同赛道对照：[`virajbhartiya/laya-vs-jev`](https://github.com/virajbhartiya/laya-vs-jev)（T-Rex 并排指标）。

## 垂直 / 数据 / Agent skill（增量）

1. **[JunMa11/MedJev](https://github.com/JunMa11/MedJev)**（约 53★）  
   临床笔记 → 表字段（noul/choice/score），强调院内 GPU、笔记不出网。基于增强临床笔记数据集训练；可选 TypeSafe 作基线。垂直「System One 形状」实例，不作医疗建议、未独立评测。

2. **[RenaGao/jev-dataops](https://github.com/RenaGao/jev-dataops)**（约 42★）  
   上传 →（本地规则 + Jev）筛选 → 数据报告 → LoRA/Demo 训练 → held-out loss。公共浏览器 demo **不调 Jev**；自托管才接 API。回答「这批数据值不值得训」。

3. **[KaLM-Embedding/KaLM-Jev](https://github.com/KaLM-Embedding/KaLM-Jev)**（约 33★）  
   基于 KaLM-Reranker 的本地 Choice/Score/Noul HTTP（`/v1/systemone`），Nano/Small/Large；HF Space 可试。作者展示官方示例输入上的自测答案——**不是** hosted Jev 复现。

4. **[hqman/jev-browser-skill](https://github.com/hqman/jev-browser-skill)**（约 32★）  
   隔离 Playwright + Jev 选题的 coding-agent skill（`jb-browser` / `jb`）；默认 Vercel Gateway。相对 09-21 `jev-for-chrome` / `jev-agent-browser`：偏 **agent skill 分发** 与安全边界清单（allowedOrigins、password 字段省略等）。
