## 独立评测与负结果（优先）

1. **[guming3d/decision_api_benchmark](https://github.com/guming3d/decision_api_benchmark)**（**10-13** 公开；中英 README + 冻结 `results/`）\
   在 Xuefeng Yin（Microsoft AI Apps GBB）**10-11** 已跑的 40 条中英「模型路由」题（五家候选模型描述 + 期望路由）上，**新增 OpenAI Decisions API（`gpt-6-luna`）** 三轮同协议对照；原四家（Jev / Microsoft-Decision-1 / 自托管 Laya / `gpt-4.1-mini`）数字直接引用原文，本仓未重跑。作者表（/40，三轮均值）：Jev **39.3**、Decision-1 **37.7**、LLM 36、**OpenAI Decisions 31**、Laya 20；中位决策时延 OpenAI **229 ms**（最快）、Jev 350 ms、Decision-1 541 ms；每百万决策成本 Decision-1 约 $8.6、Jev $21.7、OpenAI $29.2、LLM $141.8。关键负结果：同一套描述与路由说明下，OpenAI Decisions **三轮犯同一批 9 个错**，常把本该给 `gpt-4o` / `gpt-4.1` / `gpt-6-luna` 的请求判给最便宜的 `gpt-4.1-mini`。与 [kartikanand73](https://github.com/kartikanand73/decision-api-benchmark)（银行提现路由）是不同任务；见 [踩坑 #36](../guides/gotchas.md)。

2. **[masseater/mst-ja-decision-bench](https://github.com/masseater/mst-ja-decision-bench)**（**10-11** 起；结果站 [masseater.dev/decision-bench](https://masseater.dev/decision-bench)）\
   日语决策基准：选择 / 二值 / 分数；多数任务金标由 Claude Opus 5.5 标注（作者明文：与「真对错」不是一回事；JNLI 用人标，并报告 Opus 与人的一致率约 91.5%）。公开表（作者指数，全任务费用）：Decider V1.1 27B **80.7**、Mercury Decide **75.3**、Liquid d1 **67.3**、Solar Decide **65.4**、Jev 1.13 **64.0**、Clef **61.3**、Microsoft-Decision-1 **55.0**、GPT-6 Luna Decisions **53.4** 等。JNLI（choice）上 Liquid d1 / Decider / Mercury 的 skill 区间压过 Jev；业务规则 noul 上各家区间重叠更大。适合当「日语任务选型索引」，不要当绝对排行——标签来源与学习目的作者已写在 README 顶部。

## 数据与开放模型（方法新）

1. **[SunixLiu/decision-datagen](https://github.com/SunixLiu/decision-datagen)**（**10-13**；中英 README）\
   从用户提供的政策 PDF（合规手册等）生成 **choice / noul / score** 微调样本：共享 `state` + 类型化 `questions`、规则推导的确定性 `gold`，以及 teacher 软标签分布（对齐 [LocalLLaMA/typed-decisions](https://huggingface.co/datasets/LocalLLaMA/typed-decisions) / Jev Cookbook FINETUNING 字段）。输出 JSON 检视 + JSONL 训练；明确目标是 System One / Laya 式 encoder+决策头，**不是**对话 SFT。适合本地复刻流水线对照，不构成「生成数据已等于生产质量」的主张。

2. **[grounded-ai/agent-decision](https://github.com/grounded-ai/agent-decision)**（**10-11**；MIT；[HF 9B](https://huggingface.co/grounded-ai/agent-decision-9b) / [3B](https://huggingface.co/grounded-ai/agent-decision-3b) + [eval 集](https://huggingface.co/datasets/grounded-ai/agent-decision-eval)）\
   面向 agent 的开放决策模型：「这一步 tool call 对不对」「call / ask / decline」「是否有依据」等。训练数据来自 xLAM / BFCL / AgentDojo / τ-bench / When2Call / HaluEval，错误样本多为对正确调用的**构造性单点编辑**并再校验。作者表（未见训练 API 的固定抽样）：3B v2 全题约 **91.9%**（对 d1-3B 78.8%、v1 88.7%）；9B 在「调用是否正确 / 错在哪 / call-ask-decline」上约 **95.3%**，校准 ECE 约 0.014。局限写明：构造编辑可能比真实 agent 失误好认；AgentDojo 未见套件上注入动作检出约 81%。有 Colab showcase。
