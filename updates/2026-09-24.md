## 值得一看的工具（优先）

1. **[anishfn/shapeshift](https://github.com/anishfn/shapeshift)**（约 427★；[在线试](https://shapeshiftui.vercel.app)）  
   一个输入框随键入**变形**成日程卡 / 清单 / 分账 / 计时器等；一次 Jev 调用并行答约 14 道题（卡类型 + 是否视频通话等信号），日期金额单位等留给确定性解析。默认离线关键词分类器；有 `TYPESAFE_API_KEY` 时走 `jev-1.13.0`，失败静默回退。方法口号明确：**Jev decides, code computes**。相对 09-23 的 Jeview（调用审计网关）：本项是**面向终端用户的意图→UI** 示范，不是调试工具。

2. **[openqa-cn/jev-browser](https://github.com/openqa-cn/jev-browser)**（约 85★；CodexQA skill）  
   页内建控件索引（role/name/允许操作），Jev 只在封闭索引上选题；Playwright Chromium 执行；生成 YAML 后可 `--verify` **不经决策模型**回放。中英 README + [KNOWN_LIMITATIONS](https://github.com/openqa-cn/jev-browser/blob/main/KNOWN_LIMITATIONS.md)；知识库笔记是过关率主杠杆。相对 09-21 Chrome 移植 / 09-23 `hqman/jev-browser-skill` / `laya-ultrafast`：偏 **QA 回放与证据门禁**（`done_when` 必须可见），不是通用 computer-use agent。

3. **[allebee/jevk5](https://github.com/allebee/jevk5)**（约 46★；权重 [alibiserikbay/JevK5](https://huggingface.co/alibiserikbay/JevK5)）  
   独立 Apache-2.0 **开源权重** System One 替代：Qwen3.5-4B + 蒸馏 LoRA，SemIf 字母 logits 读出，兼容 `/v1/systemone`。作者称 [JevBench v1.4](https://github.com/fstandhartinger/jevbench) 上 76 系统里第 2、开源第一（62.04 vs Jev 1.13.0 的 63.29）；短决策 H100 约 13 ms。明确非 TypeSafe 附属、英文为主、最多 16 选项。相对 09-22 `rizzo-flow` / 09-23 AgentJev·AnyJev：带**可核榜单名次**与训练流水线说明，仍非官方平替。

4. **[1Panel-dev/laya-server](https://github.com/1Panel-dev/laya-server)**（约 37★）  
   1Panel 团队把上游 [Laya](https://github.com/NandhaKishorM/laya) 打成自托管 Docker：管理台 + API Key + `/v1/systemone`，镜像内含多语模型。相对 09-23 `ipenywis/laya-ultrafast`（本机 MLX 浏览器环）：本项是**可部署的 Laya 网关**，方便把兼容客户端指到自建端点。

5. **[doronp/jevc](https://github.com/doronp/jevc)**（约 6★；npm `jev-compiler`）  
   把 `CLAUDE.md` / `AGENTS.md` / skill 里的规则**编译**成「窄证据题（Jev）+ 代码里的 reduce」；`scan` → `compile --lift` → PreToolUse / bouncer / toolgate / AI SDK。核心测量（`rm -rf node_modules` 同一次调用）：塌缩 verdict 题置信度约 0.13，分解证据题约 0.93–0.97。58 条离线可重放 fixture；方法密度远高于星数。与 09-22 harness / calibrator 族互补：偏 **policy-as-code 编译器**。

6. **[iamaamir/system-one](https://github.com/iamaamir/system-one)**（约 45★；npm `system-one-core`）  
   提供商无关的 TypeScript System One 运行时：同一套 `choice` / `noul` / `score` 可挂 TypeSafe Jev、本地 Reflex、任意兼容 `/v1/systemone`，或自写 `SystemOneProvider`。刻意不做路由/阈值策略（留给应用）。相对各家 SDK：解决「换上游不改决策代码」。
