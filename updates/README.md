## 新一期怎么写

沿用日期文件名，在开头注明覆盖的时间段。正文写清本期变化、值得查看的项目、使用限制或尚未确认的问题，并为每项附原始链接。有实际使用记录时注明环境和结果；没有实测就直接说明。发布后更新上表，不预填未来日期，也不把旧内容称为本周新闻。
