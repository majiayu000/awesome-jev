## 值得一看的工具（优先）

1. **[TianyuCodings/JevHarness](https://github.com/TianyuCodings/JevHarness)**（约 71★）  
   让强 LLM **写一次任务专用 harness**（特征、问题、图、记忆），冻结后再用 Jev 做运行时模糊判断；可选轨迹奖励反思再改 harness。带 Pokémon 示例存档与回放站；作者写明 Eval 提升（如 25%→75%）是**选择集上的例子**，不是未见对局的独立估计。Claude Code / Codex skill 可装。

2. **[smkrv/jev-calibrate](https://github.com/smkrv/jev-calibrate)**（约 31★，npm `jev-calibrate`）  
   在自有标注上给每个问题打 `gate` / `gate-above-confidence` / `ranker` / `unusable` / `too-few-examples` 裁决；无运行时依赖，TypeSafe 或 OpenRouter。与 09-21 已记的 [`abhixhek/jevcal`](https://github.com/abhixhek/jevcal)（`decisions.lock.json` + CI drift）**同赛道不同形状**：本项偏「问题文案能不能当闸门」的可执行报告，不替代对方的锁文件门禁。

3. **[mizchi/jev-test-filter](https://github.com/mizchi/jev-test-filter)**（约 10★）  
   读 `git diff`，对仓库内每个测试问「此变更是否可能改变结果」，输出 vitest / jest / `node --test` / Playwright / `cargo test` / `go test` 认识的过滤参数；`--exec` 直接 spawn 原 runner。无 agent 环、模型不读仓库文件。附 agent skill / Claude Code 插件。

4. **[evoke-build/evoke](https://github.com/evoke-build/evoke)**（约 10★；[evoke.build](https://evoke.build)）  
   「一句话 → 安装好的 reflex」：Jev 在封闭动作集上选题+参数，置信闸决定跑/确认/追问；CLI + git 包管理 + TS/WASM SDK。引擎可换，首适配是 Jev。测试不需 key。

5. **[agent-chaperone/agent-chaperone](https://github.com/agent-chaperone/agent-chaperone)**（约 1★，npm；[Show HN](https://news.ycombinator.com/item?id=49789538)）  
   包装既有 MCP：调用前筛参数、结果回 agent 前再筛；默认 **shadow** 只记日志；策略在文件不在 prompt。自述不是沙箱、不替代客户端权限提示、非本地-only（内容会发后端；密钥形字符串先脱敏）。阈值按 **Jev** 标定；换 OpenRouter/通用模型时概率**不可直接复用**。方法上相对 09-21 的 axi / jev-use：更偏「透明代理整条 MCP」而非单机 PreToolUse。

### 工具（优先）

1. **[kevinbadi/jev-voice](https://github.com/kevinbadi/jev-voice)**（约 62★）  
   macOS 语音桌面：本地 whisper.cpp 转写，一次 Jev 扇出在封闭动作/参数候选上选题（选而非生成），代码执行。多步任务把 [jev-ultrafast](https://github.com/browser-use/jev-ultrafast) 环移植到 Accessibility 树 / Chrome CDP。与 catalog 里的 [`moritzkremb/jev-voice-browser`](https://github.com/moritzkremb/jev-voice-browser) 同族不同壳：本项是整机语音助手，不是「只控浏览器」。

2. **[openlayer-ai/jevals](https://github.com/openlayer-ai/jevals)**（约 48★，PyPI `jevals`）  
   把 Ragas 式 / agent 轨迹评测与门禁改写成「一次请求打包多题」的 Jev 决策：离线指标、在线路由前 gate、同一 YAML/类定义。后端可走 TypeSafe / Vercel Gateway / 本地 Kev·Laya / 聊天模型模拟；自带 `calibrate` 与 OpenAI Agents / LangGraph / Claude PreToolUse 适配。与 catalog 里的 [`dayhaysoos/jevals`](https://github.com/dayhaysoos/jevals) **不同仓**；与 09-21 LangChain「Jev 当 judge」博文同赛道、偏可安装库。Alpha，作者写明 TypeSafe 直连与部分适配器用 mock/假件测过。

3. **[Rizzo-AI-Academy/rizzo-flow](https://github.com/Rizzo-AI-Academy/rizzo-flow)**（约 225★）  
   开源本地「System One 接口」：`POST /v1/systemone` 形状对齐 TypeSafe，默认 Spark-X2.5-4B + llama.cpp，读答案字母 logits、零生成 token。作者明确：**非 TypeSafe 附属、不复现 RLCD、概率默认未校准**；相对 SemIf 夹具自报大致持平。2026-09-22 README 记 runtime 从 MLX 切到 llama.cpp。相对 gotcha「开源复刻 ≠ 官方权重」的可跑、可核对实例；不升格为「平替 Jev」。
